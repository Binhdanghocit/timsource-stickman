# Timsource Stickman

Dự án game chiến thuật đối kháng 2D với quân người que. Người chơi quản lý tài nguyên, chọn loại quân và điều phối giao tranh để phá hủy căn cứ đối phương.

## Tình trạng

- Đang ở giai đoạn ý tưởng và thiết kế quân.
- Chưa chốt game engine; repository chưa có mã gameplay.
- Danh sách repo tham khảo và ghi chú giấy phép: [`references/README.md`](references/README.md).
- Roster và hướng tạo hình ban đầu: [`docs/UNIT_ROSTER.md`](docs/UNIT_ROSTER.md).
- Hướng dẫn deploy bản web lên Ubuntu Server: [`deploy/ubuntu/README.md`](deploy/ubuntu/README.md).

## Hướng prototype

1. Tạo một bản đồ nhìn ngang và hai căn cứ.
2. Thêm tài nguyên, gọi quân và AI đối thủ cơ bản.
3. Thêm các đơn vị có vai trò và khắc chế rõ ràng.
4. Bổ sung lệnh chiến thuật, cân bằng và hoạt ảnh.

Các bản clone repo bên ngoài nằm local trong `references/` để nghiên cứu, không được đẩy lên repo này. Chỉ mục nguồn được lưu tại `references/README.md` để tránh phát tán lại mã hoặc tài nguyên bên thứ ba.
